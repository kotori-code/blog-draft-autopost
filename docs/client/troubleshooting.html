よくあるエラーと対処法

探し方

「記事作成」シートの 「エラー内容」 の列に出ている文言を、Ctrl + F でこのページから探してください。

  1. 画面の動きがおかしいとき
  2. シートの入力に関するエラー
  3. AI（OpenAI）に関するエラー
  4. WordPress に関するエラー
  5. 「注意:」で始まる文
  6. 設定に関すること
  7. それでも解決しないとき
直したあとは エラーになった行は、原因を直してから、もう一度チェックを入れれば作り直せます。チェックは自動で外れています。

1画面の動きがおかしいとき

症状原因対処法
ステータスが「作成中」のまま変わらない 本文の作成には 1〜2 分かかります 2〜3 分待ってください。10 分たっても「作成中」のまま なら、途中で止まっています。ステータスを「タイトル案あり」に戻し、もう一度「本文を作成」にチェックを入れてください
チェックを入れても何も起きない（チェックが付いたまま） チェックで動く仕組み（トリガー）が登録されていない 管理者の方が、拡張機能 → Apps Script を開き、上の関数の選択欄で setupTriggers を選んで「実行」を押してください。許可を求められたら許可します
右下に「ほかの処理が終わらないため、実行できませんでした」 前の記事を作っている途中に、たくさんチェックを入れた 前の記事が「作成済」になってから、もう一度チェックを入れてください
右下に「○ 行目は「作成済」なので、本文は作り直しません」 同じ記事が 2 本できないようにしているため 作り直すときは、WordPress の前の下書きを削除してから、ステータスを「タイトル案あり」に戻してチェックを入れてください
灰色の列を書き換えようとすると警告が出る 自動で書き込まれる列を守るための警告です 「キャンセル」を押してください。ステータスの「公開済」以外は、手で書き換えないでください
「公開済」にしても公開日が入らない すでに公開日が入っている、またはステータスを文字で打ち込んだ 公開日が空の状態で、ステータスの ▼ から「公開済」を選び直してください
WordPress URL を開くとログイン画面になる 下書きの編集画面なので、ログインが必要です WordPress にログインすると、下書きが開きます

2シートの入力に関するエラー

エラー内容の文言原因対処法
キーワードが空です 「キーワード」の列が空 キーワードを入れてから、もう一度チェックを入れてください
「採用する案（1〜5）」で、使うタイトルの番号を選んでください 番号を選ばずに「本文を作成」を押した 「採用する案」の ▼ で番号を選んでから、もう一度チェックを入れてください
タイトル案の ○ 番が見つかりません タイトル案がまだ無い、または手で消した 先に「タイトル5案を作成」にチェックを入れてください

3AI（OpenAI）に関するエラー

エラー内容の文言原因対処法
OpenAI の API キーが設定されていません スクリプトプロパティに OPENAI_API_KEY が無い 「① API キー設定手順書」の手順 3 で登録してください
OpenAI の API キーが正しくありません（401） キーの貼り間違い、またはキーが削除された OpenAI の画面でキーを作り直し、スクリプトプロパティの値を書き換えてください（前後に空白が入っていないかも確認）
OpenAI の利用上限に達したか、短時間に送りすぎました（429） クレジットの残高が無い、または短い時間にたくさん作った OpenAI の請求（Billing）画面で残高を確認し、少なければクレジットを購入してください。残高があるなら、数分待ってからやり直してください
OpenAI 側で一時的な障害が起きています（500 番台） OpenAI のサーバーの不調 しばらく（30 分〜数時間）待ってから、やり直してください
OpenAI への依頼に失敗しました（○○）。モデル名などの設定を確認してください モデル名（OPENAI_MODEL）の書き間違い、または提供が終わったモデル スクリプトプロパティの OPENAI_MODEL を確認してください。直らない場合は開発担当にご連絡ください
タイトル案が ○ 案しか返ってきませんでした AI の返事がたまたま少なかった もう一度「タイトル5案を作成」にチェックを入れてください
見出しが ○ つで返ってきました（3 つの予定） AI の返事がたまたま決まった形でなかった もう一度「本文を作成」にチェックを入れてください（WordPress には保存されていません）
AI が作成を断りました キーワードや補足メモに、AI が書けないと判断した内容が含まれる キーワード・補足メモの表現を変えてから、やり直してください

4WordPress に関するエラー

このエラーのときは、AI の記事はできていますが WordPress に保存できていません。直してから「本文を作成」にチェックを入れると、記事を作り直して保存します（1 本約 7 円がもう一度かかります）。

エラー内容の文言原因対処法
WordPress の接続設定がありません スクリプトプロパティに WP_BASE_URL・WP_USERNAME・WP_APP_PASSWORD のどれかが無い 文言に出ている名前を「① API キー設定手順書」の手順 3 で登録してください
WordPress に接続できませんでした サイトの URL の書き間違い、またはサイトが止まっている WP_BASE_URL を確認してください（https:// から始まり、最後に / を付けない）。ブラウザでサイトが開けるかも確認します
WordPress のユーザー名かアプリケーションパスワードが違います（401） 貼り間違い、またはアプリケーションパスワードが取り消された WordPress で専用ユーザーのアプリケーションパスワードを作り直し、WP_APP_PASSWORD を書き換えてください。WP_USERNAME がメールアドレスではなくユーザー名になっているかも確認します
専用ユーザーに記事を作る権限が無いか、セキュリティプラグインに止められました（403） 専用ユーザーの権限グループが「購読者」など、またはセキュリティプラグインが外部からの保存を止めている 権限グループを「寄稿者」（または「投稿者」）にしてください。それでも直らない場合は、セキュリティプラグインの設定（REST API の制限）を、サイトの管理会社か開発担当にご確認ください
WP_BASE_URL が違うか、WordPress の REST API が使えない設定になっています（404） URL に余分な部分（/wp-admin など）が付いている、または REST API が止められている WP_BASE_URL をサイトのトップの URL にしてください。直らない場合は、サイトの管理会社か開発担当にご確認ください
WordPress のサーバーで一時的なエラーが起きています（500 番台） サーバーの不調 しばらく待ってから、やり直してください
WordPress から記事番号が返ってきませんでした サイト側のプラグインなどが、通常と違う返事をした WordPress の投稿一覧に下書きができていないか確認してください。できていなければやり直し、続く場合は開発担当にご連絡ください

5「注意:」で始まる文

下書きは保存できています。内容を確認して、必要なら WordPress で手直ししてください。

エラー内容の文言意味対処法
注意: 説明文が ○ 字です。120 字以内に直してから使ってください 説明文（メタディスクリプション）が長い 説明文を 120 字以内に縮めてから、WordPress（または SEO プラグイン）に設定してください
注意: 本文が ○ 字（見出しを除く）で、短めです 本文が 1,800 字に届いていない 内容が足りていれば、そのままでかまいません。足りなければ手で書き足すか、WordPress の下書きを削除して作り直してください

6設定に関すること

症状・文言原因対処法
共通設定を書き換えたのに、記事に反映されない 「反映する」にチェックを入れていない 表の下の「反映する」にチェックを入れ、「最後に反映した日時」が更新されたか確認してください
貼り付けた文章が、下の行に分かれてしまった セルを選んだだけで貼り付けた Ctrl + Z で元に戻し、セルを ダブルクリック してから貼り付けてください
「個別設定」に「○○」の指示文がありません 「個別設定」の A 列の「タイトル生成」「本文生成」の文字を変えた、または消した A 列を「タイトル生成」「本文生成」に戻して、「反映する」にチェックを入れてください
○○ に設定がありません 「共通設定」や「個別設定」の 2 行目より下が空になっている 消してしまった場合は、Google スプレッドシートの ファイル → 変更履歴 から前の版に戻せます

7それでも解決しないとき

開発担当にご連絡ください。次の 3 つを教えていただくと、早く調べられます。

  1. 何行目の記事か（キーワード）
  2. 「エラー内容」の文言（そのままコピー）
  3. だいたいの日時
API キーやパスワードは送らないでください 調べるときに、お預かりする必要はありません。
