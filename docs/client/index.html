ブログ記事 下書き自動作成

スプレッドシートにキーワードを入れると、AI が記事の下書きを作り、WordPress に保存します

① API キー設定手順書
最初に 1 回だけ行う設定です。OpenAI の API キーと WordPress のアプリケーションパスワードを作り、仕組みに登録します（約 20 分・管理者の方向け）
② 使い方マニュアル
毎日の使い方です。キーワードを入れてから記事を公開するまでを、画面の写真つきで最短手順にまとめました（担当者の方向け）
③ トラブルシューティング
「エラー内容」の列に出る文言ごとに、原因と直し方をまとめました。困ったときに開いてください

はじめて使うときの順番

  1. 管理者の方が「① API キー設定手順書」で設定する
  2. 担当者の方が「② 使い方マニュアル」を見ながら 1 本作ってみる
  3. うまくいかないときは「③ トラブルシューティング」を見る
この仕組みが自動でしないこと 記事の公開・画像の設定は行いません。AI の誤りがそのまま公開されないよう、下書きを担当者の方が確認してから公開してください。
この資料はブラウザで開いて読むか、印刷（Ctrl + P）して使えます。
